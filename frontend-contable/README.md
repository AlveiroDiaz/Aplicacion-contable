# Frontend — Motor Contable

Este es el frontend en Next.js del proyecto. La documentación completa (cómo levantar todo, decisiones de diseño, pruebas, etc.) está en el [README de la raíz del repositorio](../README.md).

## Arranque rápido (solo este frontend)

```bash
npm install
npm run dev
```

Necesita el backend corriendo y la variable `NEXT_PUBLIC_API_URL` apuntando a él (ver `.env`).
